# Editable chemical connectivity files

CML files contain explicit P/S/N/Si/C connectivity and formal charges, with phenyl groups expanded. They have no calculated coordinates. `motif-*` files are notebook topology readings or hypothetical structures; they are not real optimised/isolated species. Atom IDs are local editing identifiers, not a recovered notebook atom map. N–S candidate files do not imply chemical identification. These files can be edited in CML-capable chemical software; SVGs remain the publication-layout source.
